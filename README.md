# ADDAC406 Clock Bender firmware

**Open the installer: https://addacsupport.github.io/addac406-firmware/**

Install the latest firmware on the ADDAC406 Clock Bender straight from the
browser, over USB, with no tools to install.

- Use **Chrome** or **Edge** on a computer. Other browsers can't talk to USB
  devices.
- Your saved settings and pot calibration are kept: the update never writes the
  part of the memory where they are stored.
- Prefer a desktop tool? Each release's `.hex` file is in
  [`firmware/release/`](firmware/release/) and installs with PJRC's
  [Teensy Loader](https://www.pjrc.com/teensy/loader.html).

---

This repository is published automatically from ADDAC's firmware repository on
every release, so changes made here are overwritten.

Install

This browser can't program the module. Use Chrome or Edge on a computer, or download the file below and use the Teensy Loader.

  1. Connect the module's USB port (on the Teensy board at the back) to the computer.
  2. Press Restart module and pick the Teensy port. The module restarts into programming mode and its display stops updating.
  3. Press Install and pick the Teensy bootloader.
  4. Wait for the progress bar to finish. The module restarts with the new firmware.

Release notes

If the module isn't found

  • Try another USB cable: many only carry power.
  • If Restart module shows no Teensy port, the module may already be in programming mode (for example after an interrupted update). Use The module is already in programming mode and press Install.
  • You can also put it in programming mode by pressing the small button on the Teensy board once.

Without the browser

Download the firmware file and install it with PJRC's Teensy Loader: open the file, press the button on the Teensy board, and the loader programs it.
